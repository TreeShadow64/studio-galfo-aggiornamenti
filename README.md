# Studio Galfo · aggiornamenti

Questo archivio contiene **soltanto** i pacchetti degli aggiornamenti dell'app "Studio Galfo", nella sezione
**Releases**. Non contiene codice sorgente né dati di nessuno.

- I pacchetti sono **cifrati** e accompagnati da un manifesto **firmato** (Ed25519).
- L'app li scarica da sola e li installa **solo** se la firma è valida e il file è integro.
- Non serve scaricare niente da qui a mano.
